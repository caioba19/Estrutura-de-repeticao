# Estruturas de Decisão e Repetição em TypeScript

Resolução da lista **"TypeScript – Estruturas de Decisão e Repetição"**, com 30 questões no estilo ENADE, feita em TypeScript puro e executada no terminal com Node.js.

Cada questão está em um arquivo independente e traz a função (ou script) com a solução e alguns casos de teste que imprimem o resultado no console, incluindo valores de borda e entradas inválidas.

## Conteúdos praticados

- Condicionais: `if / else if / else`, operadores lógicos (`&&`, `||`, `!`) e `switch`
- Laços: `for`, `for...of`, `while`, `break` e `continue`
- Laços aninhados e matrizes
- Acumuladores, contadores e cálculo de média
- Validação de entrada e tratamento de erros
- Tipagem: `type`, `interface`, union types e `readonly`

## Como executar

Pré-requisito: [Node.js](https://nodejs.org/) 18 ou superior.

```bash
git clone https://github.com/caioba19/Estrutura-de-repeticao.git
cd Estrutura-de-repeticao
npx tsx questão1.ts
```

Troque o nome do arquivo para rodar outra questão. Os arquivos das questões 1 a 12 usam acento (`questão`) e os das questões 13 a 30 não (`questao`).
